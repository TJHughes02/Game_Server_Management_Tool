# Capstone Project_Hughes_Werling

## Private Server Management Tool

## Description
We are seeking to develop a web-based server management tool that allows users to manage game servers remotely using remote console (RCON). This project aims to simplify server management for individuals who host private RCON game servers in a larger scale.
### Frontend
This tool will feature a user-friendly front end for issuing server commands, monitoring server status, and managing configurations and user permissions. It will primarily be made using ReactJS and JavaScript
### Backend
The backend will be built primarily in Python and make use of a database to store server data, user data, and user permissions. Aside from Python, the backend will also make use of SQL, Flask, and RCON
